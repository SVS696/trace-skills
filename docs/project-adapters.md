# Настройки проектов

Файлы `setups/rtl.json` и `setups/haeze.json` задают шесть маршрутов TRACE, переменную окружения с путём проекта, путь и SHA-256 основного шаблона. В них также указаны системы планирования и публикации. После постановки пользователь выбирает дальнейший маршрут.

Прочитайте действующие инструкции проекта в `AGENTS.md` и `CLAUDE.md`. Затем откройте скилл выбранного маршрута. Проект определяет источники требований, работу с паспортами задач и Git, правила публикации в Redmine, Jira или Confluence. TRACE определяет порядок анализа, объединения материалов и проверки исправлений.

## Как проверить шаблон

Передайте путь к своей рабочей копии вместо пути из примера.

```bash
RTL_PROJECT_ROOT=/absolute/path/to/RTL python3 scripts/validate_setup.py setups/rtl.json
HAEZE_PROJECT_ROOT=/absolute/path/to/HAEZE python3 scripts/validate_setup.py setups/haeze.json
```

Если содержимое шаблона изменилось, проверка сообщает ожидаемый и фактический SHA-256. Сверьте файл с каноническим шаблоном проекта. Обновите контрольную сумму в настройках TRACE после согласованного изменения самого шаблона. Запустите проверку повторно.
