# Упрощённый технический русский

Используй текст пользователя и доступный проектный глоссарий. Если пользователь дал исходник и редакцию, сравни их. Для проверки одного текста оцени его ясность. Для проверки сохранности смысла нужен исходник.

## Выбери результат по просьбе пользователя

- **Адаптировать.** Верни готовый текст в исходной структуре. Если неопределённость влияет на действие, добавь после текста открытый вопрос. Когда пользователь просит правку файла, внеси её в указанный файл.
- **Проверить.** Оставь исходник без изменений. Для каждого существенного замечания укажи место, короткий фрагмент, возможные трактовки или потерю смысла и минимальную правку. Если для правки нужно решение владельца, задай точный вопрос. Если замечаний нет, укажи, что проверил.
- **Адаптировать и проверить.** Верни готовый текст, затем назови существенные пробелы или расхождения, которые остались после сверки.

## Сверь смысл

1. Определи вид текста. Для требования сохрани исполнителя, условие, обязательность, действие, объект и наблюдаемый результат. Для инструкции сохрани адресата, порядок шагов и точку остановки. Если источник называет причину правила, сохрани её отдельно от обязательного поведения. Для архитектурного решения сохрани причину выбора и предел применимости.
2. Раскрой отглагольные обороты. Назови исполнителя только тогда, когда его указывает источник. Раздели независимые действия. Если несколько изменений должны произойти вместе, сохрани это условие.
3. Сохрани отрицание, границы диапазонов, исключения, сроки, единицы, права и запреты. Проверь различие между «вправе», «должен» и описанием факта. Перенеси точные имена API, статусы, значения, ссылки, цитаты и примеры кода. Редактируй пояснение к коду.
4. Сверь итог с исходником по каждому условию и исключению. Проверь существующий глоссарий. Для ТЗ и требований используй расширение, которое соответствует назначению документа. [Правила и источники TRACE](../../rules/technical-writing.md)

**Пример проверки.** Источник: «Только администратор вправе отменить заявку до начала обработки». Редакция: «Администратор отменяет заявку до начала обработки». Редакция превратила право в описание действия и потеряла ограничение по роли. Исправление: «До начала обработки только администратор вправе отменить заявку».

Профиль опирается на правила УТР для технического текста. Заявление о соответствии конкретному стандарту требует проверки его применимых положений. [ГОСТ Р 58049-2017](https://protect.gost.ru/gost/details/4183a5cf-a3af-4e95-97bd-c7bb4bb27063)
