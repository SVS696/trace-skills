# Проверка языка требования

Прочитайте только `rules/technical-writing.md`. Подготовьте русскую и английскую версии требования по приведённому источнику. Для каждой версии отдельно укажите открытые вопросы. Работайте только с текстом.

> Клиент вправе отправить ту же заявку повторно. При повторной отправке сервис обязан вернуть идентификатор исходной заявки, кроме заявок в статусе CLOSED. Поведение для CLOSED определит владелец продукта.

При проверке ответа сравните права клиента, обязанность сервиса и исключение `CLOSED` в обеих версиях. Проверьте, сохранил ли автор два пробела: признак повтора и ответ сервиса для закрытой заявки. Владелец решения известен для второго вопроса. Если редактор заменил разрешение «вправе» на «должен», укажите, кто и в каком режиме проверяет исправленный текст перед передачей.
